# Farai Kapopo — Personal Budget

A budgeting web app that automatically splits income across 6 customizable categories (tithe, bills, freedom, fun, education, savings) using an adjustable envelope system. Built with vanilla HTML, CSS, and JavaScript with localStorage persistence.
## 🌐 Live Site

[View the live site](https://farairudokapopo-code.github.io/purpose-budget/)

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 📁 Structure

- `index.html` — page structure and content
- `styles.css` — all styling
- `script.js` — interactive behavior
